## The big architectural change: project ≠ target (slices 1–3)

Memory `project-model-umbrella-and-target` is the source of truth. Summary:

- **A project is the umbrella** for all tracking. It **references a target** TRE set:
  `target.kind = client | standalone`, with `clientPath`/`cfgPath`/`treDir`/`pattern`. The
  client is a **property** of the project, never the project's identity.
- **Identity:** `projects\<name>\` (umbrella) + `studios\<name>\` (tracking, whitespace-free
  per D-06). Keyed by **project name**, NOT the client folder.
- `initProject(projectFolder, {targetPath, targetKind, projectName, …})` decoupled. One-click
  detected-client bind quick-creates `projects\<ClientName>`. Non-client/browse-folder →
  `target.kind:'standalone'`.
- **Open Project** is an in-app dialog (`ProjectListDialog`) listing projects as cards —
  reads the authoritative **studios store** (`listProjects` → `getStudiosRoot`), so a project
  shows even if its `projects\<name>` folder is missing; `openWorkspace` remkdirs it.
- **Auto-mount moved into `openWorkspace`** (`services/treAutoMount.ts`) → every open (fresh
  bind AND reopen via recents/Open Project) populates the TRE browser. `initProject` no
  longer mounts (it calls openWorkspace).
- **Test isolation:** data root is env-overridable via `SWG_TOOLKIT_DATA_ROOT`; vitest
  `setupFiles` (root + renderer configs) point it at an OS temp dir. Fixed the bug where
  unit tests polluted the real `%LOCALAPPDATA%\swg-toolkit\studios` (was ~120 junk dirs).

## Ground-truth verifications (the #1 project constraint — done right)

Verified against `../swg-client-v2` source (the authoritative oracle), NOT docs/consensus:

- **`TreeFile.cpp`** (`reference-treefile-searchtree-precedence` memory): searchTree config
  lives in `.include`'d `swgemu_live.cfg` (NOT root `swgemu.cfg`). install loop = sku asc →
  priority 0→max asc; nodes sorted **priority DESC**; **first node containing a file wins**;
  ties → later-added. Implemented in `clientSearchOrder.ts`; verified vs real SWGEmu
  (`default_patch.tre` slot 25 wins → `bottom.tre` slot 0).
- **`ConfigFile.cpp:370-392`**: `.include` requires **quotes**, copies the entire quoted
  string (whitespace preserved, no truncation), `loadFile()→CreateFile()` opens **absolute
  paths** directly. → justified moving swgtoolkit.cfg into the studio.
