**Analog A:** `packages/renderer/src/services/clientLocator.ts` lines 309-337 (`_detectTreVersion` — fd open + readSync + close pattern)

**Binary file-open + read pattern** (`clientLocator.ts` lines 324-337):

  const header = Buffer.alloc(8);

**Analog B:** `packages/renderer/src/services/treMount.ts` lines 71-130 (`decodeMountEntriesColumnar` — DataView + Uint8Array + little-endian read + null-terminated string decode)

**LE uint32 + null-terminated string decode pattern** (`treMount.ts` lines 75-128):
```typescript
const buf = new DataView(blob);
const u8  = new Uint8Array(blob);
const entryCount = buf.getUint32(0, true);          // true = little-endian
if (entryCount === 0) return [];
// … read header fields …
const decoder = new TextDecoder('utf-8');
function readCStr(dataOffset: number, relativeOffset: number): string {
  let end = dataOffset + relativeOffset;
  while (end < u8.length && u8[end] !== 0) end++;
  return decoder.decode(u8.subarray(dataOffset + relativeOffset, end));
}
```

**Imports pattern** (copy from `clientLocator.ts` lines 36-38):
```typescript
import path from 'path';
import fs from 'fs';
```

**TOC-specific notes for implementation:**
- Read 36-byte header into `Buffer.alloc(36)` via `fs.readSync(fd, buf, 0, 36, 0)`
- Parse with `buf.readUInt32LE(offset)` — Buffer LE methods are cleaner than DataView for a Node.js file-read context; DataView is appropriate when decoding an `ArrayBuffer` already in memory
- Validate magic bytes at offset 0: `buf.readUInt32LE(0) === 0x544F4320` (` COT`) and version at offset 4: `buf.readUInt32LE(4) === 0x30303031` (`1000`)
- `numberOfTreeFiles` at offset 28; `sizeOfTreeFileNameBlock` at offset 32
- Read `sizeOfTreeFileNameBlock` bytes starting at byte 36: null-separated `.tre` name list
- No close analog for this full reader in the renderer codebase — this is genuinely new TS binary-parse work (see "No Analog Found" section)

**Error handling pattern** (copy from `clientLocator.ts` `_detectTreVersion`):
```typescript
try {
  // … open, read, validate, close …
  return result;
} catch {
  return fallback; // never throw from detection functions
}
```
