## Byte-Exact Round-Trip Gate (standing project gate)

- **`.toc` reader (header):** assert parsed header fields == the literal values above against the **real** `sku0_client.toc` (not synthetic). This is the de-anchoring guarantee.
- **`.toc` reader (full index, H1):** assert `readTocIndex` resolves `string/ja/space/space_faction.stf` → `treeFileIndex=42` / `patch_15_02.tre` against the real file; ALSO assert the 3-entry synthetic fixture CI test resolves the duplicate path to `treeFileIndex=0` (binary-search result, NOT `treeFileIndex=1` which KEEP FIRST / lowest-index would return). Both must pass before Plan 03 is done.
- **CRC port (W3):** `crc32('appearance/mesh/thm_tato_imprv_building_s09_r0_mesh_l4.msh') === 3830594` in crc32.test.ts; executor must confirm 3830594 against Crc.cpp before merging.
- **Non-destructive deploy (B3):** sha256 the pre-existing override file and `client.cfg` before deploy; assert both match sha256 of the file/cfg AFTER reset. The pre-existing file must be RESTORED (not absent).
- **Cross-deploy prune (H2):** after two sequential deploys where the second omits a file present in the first, assert the omitted file is gone (no orphan).
