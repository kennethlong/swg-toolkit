# Phase 04.4 Plan 06: TreCodec Pluggable Compression Seam Summary

**D-21's pluggable TRE codec interface (TreCodec.h/.cpp) now covers BOTH per-entry payload compression AND archive TOC/name-block compression, via three explicitly-named registry lookups (codecForCompressor, codecForTreVersion, codecForBlockCompressor) backed by two stock codecs (StoredCodec, ZlibCodec) — zero behavior change for existing 0004/0005/v6000 archives.**

## Performance

- **Duration:** ~45 min
- **Tasks:** 2 (TDD RED / GREEN)
- **Files modified:** 7 (2 created: TreCodec.h/.cpp; 5 modified: Zlib.h/.cpp, TreArchive.cpp, TreBuilder.cpp, CMakeLists.txt) + 1 test file created

## Accomplishments

- Implemented `TreCodec.h`/`.cpp`: a `TreCodec` interface (`inflate`/`deflate`) with two stock singleton codecs (`StoredCodec` for compressor code 0, `ZlibCodec` for compressor code 2) and three registry lookups — `codecForCompressor` (payload read), `codecForTreVersion` (payload write), `codecForBlockCompressor` (TOC/name-block read AND write, round-3 widened scope).
- Extracted `TreBuilder::zlibCompress`'s zlib `compress2` body into a new shared free function `treDeflate()` in `Zlib.h`/`.cpp`, alongside the existing `treInflate()`. `TreBuilder::zlibCompress` is now a thin wrapper; `ZlibCodec::deflate` calls the same function — avoiding a `TreCodec.cpp` ↔ `TreBuilder.cpp` circular include.
- Rewired `TreArchive::parse()`'s TOC and name-block inflate call sites (and their `tocCompressor == 0` / `blockCompressor == 0` bypass branches) to a single uniform `codecForBlockCompressor(...)` dispatch, formalizing the old bypass as a registered `StoredCodec` instead of a call-site special case.
- Rewired `TreArchive::extractEntry`/`extractAt`'s payload inflate calls to `codecForCompressor(...)`, and `TreBuilder::build`'s payload deflate call to `codecForTreVersion(...)`, preserving the exact existing try/classify surrounding logic (MOUNT-05) and V6000 write-refusal (`isEnumerateOnly`) unchanged.
- Rewired `TreBuilder::build`'s TOC and name-block deflate call sites to `codecForBlockCompressor(2)` (round-3 widened scope), preserving byte-identical header field emission (`tocCompressor`/`blockCompressor` = 2 or 0 depending on whether compression was beneficial).
- Added `packages/native-core/test/tre-codec.test.ts`: black-box regression/parity tests (all pass unchanged, since this is a pure internal seam refactor) plus a source-level RED/GREEN gate that reads the actual `.cpp`/`.h` source text and asserts the codec-dispatch functions are wired in and the old bypass branches are gone — genuinely fails on unmodified code, genuinely passes after the implementation.

Logged here for visibility, not filed to `deferred-items.md` since it is a test-fixture-only adjustment with no production impact identified so far.
