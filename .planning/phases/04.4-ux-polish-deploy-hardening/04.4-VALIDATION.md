> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest (unit/jsdom) + Playwright (real-Electron E2E) + native-core harness |
| **Config file** | `vitest.config.ts` / `playwright.config.ts` |
| **Quick run command** | `npm test` (vitest) |
| **Full suite command** | `npm test && npm run build && npx playwright test` (build-before-E2E per D-11) |
| **Estimated runtime** | ~60s unit; ~5–10 min full with E2E cold launches |

## Sampling Rate

- **After every task commit:** Run `npm test` (vitest quick pass)
- **After every plan wave:** Run full suite (build + Playwright real-Electron specs)
- **Before `/gsd:verify-work`:** Full suite must be green
- **Max feedback latency:** 600 seconds
