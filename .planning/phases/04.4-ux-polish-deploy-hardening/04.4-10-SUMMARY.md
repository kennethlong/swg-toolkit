# Phase 04.4 Plan 10: Delete-Project UI (Sketch 017 Variant B) Summary

**Per-row kebab delete menu, deploy-model-aware confirm modal, and an 8s undo toast with a reactive dimmed-row trash view — built on top of 04.4-01's delete/restore service and wired to sketch 017's approved Variant B.**

## Performance

- **Duration:** ~60 min
- **Tasks:** 3
- **Files modified/created:** 9 (5 created, 4 modified)

## Accomplishments

- `DeleteProjectConfirmModal.tsx`: shared confirm modal read by manifest to pick the correct
  plan-line variant (cfg-model restore / loose-model revert / never-deployed "nothing to
  restore"), plus the amber "currently open" warn-line and an in-flight Delete/Cancel guard that
  makes a rapid double-click result in exactly one `deleteProject()` call.
- `ProjectListDialog.tsx` / `WorkspaceEntry.tsx`: per-row ⋯ kebab menu (Open · Reveal studio
  folder · — · Delete project…) with `stopPropagation()` so the kebab never also opens the row's
  project, plus a shared click-outside/Escape dismiss pattern (element #17).
- **Round-2 reactive fix**: both row surfaces now derive their displayed rows from
  `useDeleteUndoStore`'s `pending` array via `useMemo`, not a one-shot re-fetch — a delete or
  restore is reflected on screen immediately even while the surface stays mounted across the
  mutation (the exact "delete without closing the dialog" scenario sketch 017 demonstrates).
- `ProjectListDialog` renders the inline dimmed/dashed/struck-through recoverable row with a
  Restore button (dialog-only, per the sketch); `WorkspaceEntry`'s recents row simply
  disappears — no dimmed remnant there.
- `DeleteUndoToast.tsx`: a single global toast, mounted once in `App.tsx`, that diffs the
  `pending` array against its previous render to detect both new deletes (🗑/⚠ variant keyed off
  `restoreErrors`) and restores from ANY surface (this toast's own Undo, or the dimmed row's
  Restore button) — firing the round-2 post-restore confirmation toast either way, with copy
  that never implies a client re-deploy (locked undo contract).
