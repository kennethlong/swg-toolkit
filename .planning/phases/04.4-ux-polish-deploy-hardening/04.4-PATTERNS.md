### `packages/renderer/src/services/deleteProject.ts` (service, CRUD/orchestration)

**Analog:** `packages/renderer/src/panels/deploy/DeployDialog.tsx` (`handleReset`) + `packages/renderer/src/services/changesetService.ts` (`readManifest`) + `packages/renderer/src/services/workspaceService.ts` (`getStudioDir`)

**Critical constraint (Pitfall 5 from RESEARCH.md):** `deleteProject` MUST derive `studioDir` via `getStudioDir(projectFolder)` and read the manifest via the **store-independent** `readManifest(studioDir)` — NEVER via `useWorkspaceStore.getState().studioDir` or the store-coupled `updateChangesetDeployRecord`/`clearChangesetDeployRecord` helpers, because delete is invoked from `ProjectListDialog`/`WorkspaceEntry` on projects that are typically **not** the open workspace.

**Non-fatal per-step restore, errors collected** — mirror `resetLoose`'s per-file try/catch (`looseOverrideDeploy.ts:176-201`):
```typescript
export function resetLoose(record: LooseDeployRecord): void {
  for (const f of record.writtenFiles) {
    if (f.preExisted && f.snapshotPath) {
      try {
        fs.copyFileSync(f.snapshotPath, f.destPath);
        fs.unlinkSync(f.snapshotPath);
      } catch (e) {
        console.error('[resetLoose] restore failed:', f.destPath, e);
      }
    } else if (!f.preExisted) {
      try { fs.unlinkSync(f.destPath); } catch { /* non-fatal */ }
      try { fs.rmdirSync(path.dirname(f.destPath)); } catch { /* non-fatal */ }
    }
  }
}
```
Delete's restore-first step must collect failures the same way (array of `{ step, error }`) rather than throwing on the first per-step failure — D-05 requires "non-fatal per-step but failures surfaced" (surface via the toast's ⚠ restore-failure variant, D-04).

**Workspace-close-on-delete-of-open-project:** use `useWorkspaceStore.getState().close()` (`workspaceStore.ts:100-102`) exactly like any other "return to idle" call site — no new close logic needed.

**`.trash` parking:** atomic-rename pattern, mirrors `writeManifest`'s tmp+rename discipline (`changesetService.ts:70-76`):
```typescript
export function writeManifest(studioDir: string, manifest: WorkspaceChangesetManifest): void {
  const p = getManifestPath(studioDir);
  const tmp = p + '.tmp';
  fs.mkdirSync(path.dirname(p), { recursive: true });
  fs.writeFileSync(tmp, JSON.stringify(manifest, null, 2), 'utf8');
  fs.renameSync(tmp, p); // atomic on same-volume rename
}
```
For parking use `fs.renameSync(studioDir, path.join(studioRoot(), '.trash', `${id}-${token}`))` — same same-volume-rename safety property. Validate the constructed trash path with `isConfinedToRoot` (`pathSafety.ts:58-62`) before the rename, per the V5 threat entry in RESEARCH.md.

export function isVirtualPathSafe(vp: string): boolean {
  if (!vp || vp.trim() === '') return false;
  if (vp.includes('..')) return false;
  if (vp.startsWith('/') || vp.startsWith('\\')) return false;
