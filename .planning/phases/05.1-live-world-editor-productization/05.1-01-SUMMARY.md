# Phase 05.1 Plan 01: .ilf ADD/REMOVE Groundwork + REBIND_REFUSED Fix + CORE-05 Real-Asset Gate Summary

**ilf.ts gained addNode/removeNode with byte-exact round-trip coverage, decorationPersist.ts's assembleDecorationEdit now branches on a kind='edit'|'add'|'remove' discriminator behind one result shape, decorationResultLabel() no longer leaks a raw REBIND_REFUSED code, and .ilf is now registered in the CORE-05 cross-package standing gate with a REQUIRED (not skip-on-absent) fixture extracted from a real client install.**

## Performance

- **Tasks:** 5/5 (4 auto + 1 checkpoint, checkpoint approved)

## Accomplishments

- Closed a live SC1 defect: `decorationResultLabel(REBIND_REFUSED)` previously fell through to `"unknown result (-5)"`; now returns a human-readable, `/refused/i`-matching string, with all 11 other existing cases unchanged.
- Added `addNode`/`removeNode` pure mutators to `ilf.ts` (dependency-free, matching `editNodeTransform`'s clone-map idiom), each proven byte-exact through `parseIlf -> serializeIlf` round-trips, including within-cell `rowIndex` correctness verified via `resolveRowIndex` (not array position) and fail-closed throw-on-missing-row behavior for `removeNode`.
- Widened `decorationPersist.ts`'s `assembleDecorationEdit` with an optional `kind?: 'edit' | 'add' | 'remove'` field (default `'edit'`, 100% backward compatible with the proven live pipeline). `'add'` requires `edit.cellName` and calls `addNode`; `'remove'` resolves the target row the same way `'edit'` does and calls `removeNode`. All three kinds share one `DecorationPersistResult` shape, now including a `cellName` field, and honor `mirrorToStockIlf` identically.
- Registered `.ilf` in `packages/harness/fixtureRegistry.ts`'s CORE-05 standing gate exactly like every other binary format this project ships (tre/iff/dtii/stf/mesh): a hand-built, independently-encoded byte-recipe fixture PLUS a REQUIRED real-client-extracted fixture. Per the cross-AI crew's C5 finding, the real-asset lane is a fail-loud assertion with no skip-on-absent escape hatch.
- Extracted a real `.ilf` (`aakuan_talus_cave.ilf`, 17542 bytes) from the confirmed-present `D:/SWG Infinity/SWG Infinity/Live` client into `packages/harness/fixtures-real/ilf/` (gitignored, read-only extraction per D-09/D-10 asset-safety doctrine) and ran the addNode/removeNode byte-exact round-trip against it.
