## Sampling Rate

- **After every task commit:** Run the touched package's `pnpm --filter <pkg> test`
- **After every plan wave:** Run `pnpm -r test` + `tsc --noEmit`
- **Before `/gsd:verify-work`:** Full suite green + `.ilf` byte-exact round-trip gate green
- **Max feedback latency:** 120 seconds
