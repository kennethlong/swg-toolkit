# Phase 05.1 Plan 07: HOST_CMD Channel Read/Write Primitives (C++) Summary

**Implemented the C++ read/write halves of Plan 03's LIVE_HOST_CMD region — an agent-side seqlock retry-read (`channelReadHostCommand`) and code-before-epoch result publish (`channelWriteHostCommandResult`) mirroring the existing REBIND/RESULT idioms exactly, plus a host-side N-API `writeHostCommand` export mirroring `writeRebind`'s argument-validated, truncation-safe shape — both sides build clean and round-trip verified via a real-native-addon test, with no behavior wired yet (Plan 09's job).**

## Accomplishments

- `channelReadHostCommand(HostCommand* out)` in `channel.cpp` — line-for-line structural mirror of `channelReadRebind`: seqlock step-1 odd-bail, copy epoch/action/str1/str2/id/vec3 from the mapped view, seqlock step-2 torn-check
- `channelWriteHostCommandResult(int32_t code, uint32_t epoch)` in `channel.cpp` — line-for-line structural mirror of `channelWriteResult`: `InterlockedExchange` on `hostCmdResultCode` FIRST, `hostCmdResultEpoch` LAST (code-before-epoch discipline)
- `WriteHostCommand` N-API binding in `channel_binding.cpp` — validates all 7 args (name/epoch/action/str1/str2/id/vec3), truncates str1/str2 to 255/127 chars + zero-fills before memcpy (never overflows the fixed 256/128-byte slots), parses `id` via `_strtoui64` (same as `writeRebind`'s `buildingId`), accepts `vec3` as either `Float32Array(3)` or `number[3]`, seqlock-writes the HOST_CMD region (1440-1855) without ever touching the agent-authoritative RESULT_CODE/RESULT_EPOCH words (1856-1863)
- Registered `writeHostCommand` in `addon.cpp`'s exports block, forward declarations, and module-doc comment (also backfilled the pre-existing `writeRebind` doc-comment gap)
- Agent DLL (`cmake --build`, Release) and host N-API addon (`cmake-js build`/`rebuild`) both rebuilt and confirmed compiling clean; artifact mtimes verified newer than every edited source after each rebuild
- New `write-host-command.test.ts` (6 tests) exercises the REAL compiled native addon end-to-end: export-is-a-function, malformed-args TypeError, channel-not-open Error, full round-trip through `readChannelView`'s raw byte offsets (epoch/action/str1/str2/id/vec3 all independently verified via `DataView`), `number[]` vec3 acceptance, and str1/str2 truncation-never-overflow
