**Core pattern — non-mutating array edit, fail-closed on missing target** (lines 203-228,
`editNodeTransform`, the exact shape to mirror for `removeNode`; RESEARCH.md's proposed
`addNode`/`removeNode` bodies, lines 339-358, already match this idiom verbatim):
```typescript
// Source: packages/renderer/src/services/ilf.ts:208-228 (editNodeTransform — the analog
// removeNode must structurally match: clone-map, walk with a per-cell `seen` counter,
// mutate-in-place-on-copy at the matching rowIndex, throw if never matched)
export function editNodeTransform(
  nodes: IlfNode[],
  cellName: string,
  rowIndex: number,
  transformO2p: number[],
): IlfNode[] {
  if (transformO2p.length !== TRANSFORM_FLOATS) {
    throw new Error(`ilf: transform must be ${TRANSFORM_FLOATS} floats`);
  }
  const out = nodes.map((n) => ({ ...n, transform: [...n.transform] }));
  let seen = -1;
  for (const n of out) {
    if (n.cellName !== cellName) continue;
    seen++;
    if (seen === rowIndex) {
      n.transform = [...transformO2p];
      return out;
    }
  }
  throw new Error(`ilf: no node at (cell="${cellName}", rowIndex=${rowIndex})`);
}
```

**Error handling pattern:** every mutator throws a descriptive `Error` (never returns
null/undefined on a bad index) — "fail closed rather than edit the wrong object" (module
docstring, line 21). `addNode`/`removeNode` must keep this contract: `removeNode` throws
`ilf: no node at (cell="...", rowIndex=...)` exactly like `editNodeTransform`; `addNode` has
no failure mode (append is always valid) so it should NOT throw.

**Invariant to preserve (do not violate):** within-cell NODE order is identity (module
docstring, lines 19-21). `addNode` must push to the END of the array (guarantees the highest
within-cell rowIndex, since no later node shares that cell — RESEARCH Pattern 3). `removeNode`
must filter, never sort/reorder.

export function writeWorkspaceJson(studioDir: string, meta: WorkspaceBindingMeta): void {
  fs.mkdirSync(studioDir, { recursive: true });
  const filePath = path.join(studioDir, 'workspace.json');
  const tmp      = filePath + '.tmp';
