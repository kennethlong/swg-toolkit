<interfaces>
UI-SPEC Surface 3 anatomy (018-A) — every element below is a must_have:
1. Dockview tab: `<file>.stf — Strings` + warn `●` mod-dot while dirty.
2. Crumb bar: `string/<locale>/<file>.stf · STF␠ · <N> entries (<M> shown)` (locale + magic bold,
   mono — the `STF␠` segment is a cosmetic display badge; it does NOT imply the on-disk magic is
   ASCII, per D-11 — the crumb copy stays as-is, only the underlying parser's magic check differs)
   · spacer · `⇄ Compare to base` · `＋ Stage` · `Save · run gate` (primary).
3. Toolbar: `Search keys and text…` input (filters by key AND localized text) · `＋ Add key` ·
   right count chip `<visible> / <total> keys[ · <K> modified]`.
4. The grid (flat table, virtualized): columns `key | crc32 | localized text (<locale>)`. `key`: mono,
   text color, nowrap, new rows get an inline key input. `crc32`: mono, faint, `--text-xs`,
   READ-ONLY/machine-owned, never editable; new keys display `0x········ (auto on save)`.
   `localized text`: takes remaining width, wraps, double-click to edit, modified triple-encodes.
5. Gate bar: same shared chip machine as DTII with .stf copy — running: `gate: rebuilding index +
   payload…`; pass: `✓ byte-exact round-trip · CRC index rebuilt` + `→ staged in working changes` +
   modified marks clear. Right-aligned faint mono note: `values are UTF-16LE · keys ASCII · CRC32
   auto` (D-10 erratum: this footer note stays as user-facing shorthand, but "auto" here means the
   ENGINE's on-disk semantic, NOT that this editor blindly recomputes it on every save — the actual
   save behavior is D-10's preserve-verbatim-by-default rule, implemented in this plan's Task 2).
6. Fail state: inherits 014's anatomy via the shared GateBar/FailBanner — gate-fail chip + danger
   banner naming offset + expected/got bytes + not-staged guarantee.

D-10 (must be implemented, corrects the naive reading of item 5's footer note): default save
preserves every entry's `sourceCrc` byte-identical. A separate, explicit "↻ Mark re-synced to source"
action (new, not in the original sketch — CONTEXT-flagged addition) recomputes `sourceCrc` from the
DEFAULT-LOCALE file's current text via `addon.recomputeSourceCrcFromText` (05-05) for the currently
selected row(s) only, never as a blanket save-time side effect.
