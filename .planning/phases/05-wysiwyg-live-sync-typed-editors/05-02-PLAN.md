IFF tree shape (DataTableWriter.cpp:650-664 _saveTableToIff, DataTable.cpp:444-476 load):
```
FORM DTII
  FORM 0001              <- TAG_0000 legacy also supported on read (DataTable.cpp:449-459)
    CHUNK COLS            <- int32 numCols, then numCols IFF strings (column names)
    CHUNK TYPE             <- numCols IFF strings (type-spec strings, e.g. "i", "s[required]")
    CHUNK ROWS             <- int32 numRows, then numRows*numCols cells, physical type = getBasicType()
```
