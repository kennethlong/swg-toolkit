**Version-guard onReady (D-03 / Pattern 6):**
```
savedVer = Number(localStorage.getItem(LAYOUT_VERSION_KEY) ?? '0')
if saved && savedVer === LAYOUT_VERSION:
  → api.fromJSON (catch: api.clear() + buildInitialLayout)
else:
  → buildInitialLayout() + write LAYOUT_VERSION_KEY + write LAYOUT_STORAGE_KEY
```
`onDidLayoutChange` also writes `LAYOUT_VERSION_KEY` so it stays in sync on every layout mutation.

**Active-panel auto-widen (M3):**
- `api.onDidActivePanelChange(() => { panel = api.activePanel; ... })` — no-args callback, reads `api.activePanel` from closure
- `deploy` → `panel.group.api.setSize({ width: 440 })`
- `inspector` → `panel.group.api.setSize({ width: 290 })`
- Guard: `if (!panel?.group?.api) return` (null-safe)

**Reset layout (plan-08 affordance):**
- `resetLayout()` inner function: removes both storage keys, `api.clear()`, `buildInitialLayout()`, re-writes both keys
- Exposed on `window.__resetLayout` for plan-08 menu/status-bar wiring (test-hook pattern)
