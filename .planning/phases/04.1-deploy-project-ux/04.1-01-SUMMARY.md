## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Stale vitest 2.x `.bin` shim in renderer's local node_modules**
- **Found during:** Task 2 vitest alignment verification
- **Issue:** After changing renderer's vitest from `^2.0.0` to `4.1.9` and running `pnpm install`, the old `.bin/vitest` shim in `packages/renderer/node_modules/.bin/` still pointed to the non-existent local `packages/renderer/node_modules/vitest/vitest.mjs`. This caused `pnpm --filter @swg/renderer test` to fail with `Cannot find module`.
- **Root cause:** pnpm `nodeLinker: hoisted` puts packages in root `node_modules/`, but the local `.bin` shim was created for the old separate vitest 2.x install and not cleaned up on version change.
- **Fix:** Deleted the three stale shim files (`vitest`, `vitest.CMD`, `vitest.ps1`) from `packages/renderer/node_modules/.bin/`. The root `node_modules/.bin/vitest` now correctly resolves to vitest 4.1.9 when the script runs.
- **Files modified:** `packages/renderer/node_modules/.bin/vitest*` (deleted; gitignored, not committed)
- **Commit:** 9dc4597 (fix included in the task 2 commit — the stale shims were never tracked by git)
