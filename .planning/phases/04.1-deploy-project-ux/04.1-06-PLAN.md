| Boundary | Description |
|----------|-------------|
| project name → studio path | a project folder name with spaces/odd chars feeds the resolved `.studio` path used in absolute searchTree values |
| manifest file → disk | Baseline write + migration must not corrupt an existing manifest |
| staging virtualPath → changeset dir | sealVersion copies replacement files into the changeset dir by virtualPath |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04.1-13 | Tampering | path-injection via project name | mitigate | `replace(/\s+/g,'_')` + basename only (no path separators carried into the studio id); writes confined under the app-root studios base |

| T-04.1-27 | Tampering | seal-time virtualPath escape | mitigate | sealVersion validates each delta virtualPath with shared `isVirtualPathSafe` before copy (:283-286) — M1 |
| T-04.1-SC | Tampering | package installs | accept | No new packages (RESEARCH audit: none) |
