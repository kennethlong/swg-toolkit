## Decisions Made

- `seedBaseline` uses direct `writeManifest` (NOT `sealVersion`) — `sealVersion`'s N4 guard at lines 225-230 throws "Nothing new to commit" on zero deltas; Baseline has zero deltas by design, so it must bypass sealVersion entirely
- `selectVersion(BASELINE_ID)` gets a special pristine fallback — only BASELINE_ID is exempt from the existence check (T-04-15); all other version ids still validate
- M1 path-safety guard placed BEFORE sha computation and file copy — unsafe paths fail fast with a clear error message before any disk I/O
- `getStudioDir` relocated to `process.env['LOCALAPPDATA'] ?? process.env['HOME'] ?? '.'` base — covers Windows (primary platform) and *nix test environments without hard-coding
- `copyDirRecursive` skips destination files that already exist (no clobber) — safe to call multiple times without corrupting a partially-migrated studio
