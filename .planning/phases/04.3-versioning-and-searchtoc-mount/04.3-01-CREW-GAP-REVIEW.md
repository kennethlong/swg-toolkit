# Phase 04.3 · Plan 01 — Crew UI-vs-sketch gap review (gating)

**What this is:** the output of the gating cross-AI review specced in `04.3-SCOPE.md` Plan 01.
Four independent reviewers (Cursor, Codex, fresh Opus, fresh Sonnet) diffed the as-built UI against
the authoritative sketches element-by-element; this is the reconciled, de-duplicated gap list.
Per the AGENTS.md **"Sketches are the UI contract"** rule, **every CONFIRMED gap below becomes a
`must_have` in a later 04.3 plan.**

**Confidence key:**
- **CONFIRMED** = cross-checked by ≥2 reviewers, or self-verified against the real file (file:line cited).
- **PLAUSIBLE** = single reviewer, file:line cited, not independently re-checked.
- **AMBIGUOUS** = sketch vs. another spec source conflict → **maintainer decision, do not auto-resolve**.
- **KEEP** = build behavior beyond the sketch that is a deliberate evolution; preserve, do not "fix".

faithful with a cluster of chrome/affordance gaps. Every CONFIRMED row above is a `must_have` candidate
for the 04.3 plan breakdown.
