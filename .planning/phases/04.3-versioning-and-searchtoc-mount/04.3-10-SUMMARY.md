## What Was Built

### Task 1: Per-payload enumerate-only (try-inflate-classify)

Removed the 6-line blanket `isEnumerateOnly(m_version)` throw from `TreArchive::extractEntry` (lines 307-311 in the original). The extraction path now simply attempts inflate; zlib failure surfaces as a real error (Restoration v6000) while SWG-Source v6000 plain-zlib payloads extract normally. The `isEnumerateOnly()` helper is preserved for the UI "enumerate-only" chip at the mount-info level — the runtime extraction decision is now per-payload, not per-version-tag.

Updated `extractEntry`'s doc comment to reflect the T-01-05 REVISED disposition.

### Task 2: extractMountAt + mountTreMountWithToc

**C++ data structures added:**
- `TreExtractDescriptor` and `TreExtractResult` structs in `TreArchive.h`
- `TreArchive::extractAt(descriptor, stream)` static method: T-01-02 bounds check (subtraction form) + per-payload classify (try inflate → encrypted on failure), T-01-03 bomb cap via `treInflate()`
- `TocExternalEntry` struct in `TreMount.h`
- `TreMount::addExternalEntries(archiveIndex, entries)` and `m_externalEntries` storage
- `vfsEntriesColumnar()` augmented to iterate `m_externalEntries[ai]` after each archive's internal entries in the dedup loop

**N-API bindings added (tre_binding.cpp):**
- `readLE32_binding()` inline LE reader (local to TU, avoids cross-TU header change)
- `parseTocIntoMount(tocPath, tocTreePath, mount)` static helper: reads full SearchTOC binary (36-byte header, tree-name block, TOC blob 24 bytes/entry, name block), decompresses with `treInflate()` if needed, normalizes paths, builds archiveIndex map from mount nodes, groups `TocExternalEntry` by archiveIndex, calls `addExternalEntries()`
- `ExtractMountAt`: resolves container via `mount.nodeAt(archiveIndex).path` (same lookup as `readMountEntry`), opens `FileInputStream`, calls `TreArchive::extractAt()`, returns `{ bytes: ArrayBuffer }` on success or `{ encrypted: true }` on inflate failure
- `MountTreMountWithToc`: creates TreMount from paths+priorities (same as mountTreMount), then calls `parseTocIntoMount()`, stores handle

**addon.cpp:** Forward declarations + exports registered for `extractMountAt` and `mountTreMountWithToc`.
