## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Unicode curly quotes in JSX attribute values (TS1127)**
- Found during: Task 3 tsc check
- Issue: The original DeployDialog.tsx contained Unicode curly quote characters (U+2018/U+2019) in JSX `style={{ }}` attribute string values (e.g., `'var(--color-border)'` was using `'`/`'` not `'`). These were in JSX text content in the original file (stale-warning banner) and didn't cause tsc errors there, but when the banner was removed and the file structure changed, the characters cascaded into TS1127 parse errors.
- Fix: node script replaced all U+2018/U+2019 characters with ASCII U+0027 across the file (82 replacements).
- Files modified: DeployDialog.tsx
- Commit: 0e4c980

**2. [Rule 1 - Bug] JSX IIFE pattern causing tsc cascade**
- Found during: Task 3 initial implementation
- Issue: Using `{(() => { const x = ...; return <div>...</div>; })()}` inside JSX caused the TypeScript JSX parser to produce a cascade of TS1127/TS1381/TS1382 errors on surrounding lines.
- Fix: Moved the "not found" row computation to a pre-render const variable (`showNotFoundRow`, `boundClientPath`) before the return statement; used `{showNotFoundRow && <div>...</div>}` instead.
- Files modified: DeployDialog.tsx
- Commit: 0e4c980
