## Decisions Made

- **Lane-free check uses parentRow, not currentRow.** When checking if lane L is free for a new branch node, the check is `laneEndRow[L] < parentRow` (the parent's row index), not `< currentRow` (the branch node's own row). This is because the branch connector starts visually at parentRow and runs down to the branch node — two sibling branches from the same parent (both connectors starting at parentRow) must use distinct lanes even if one sibling has already finished its subtree.

- **CSS vars exclusively.** All LaneGutter colors use CSS custom properties (`var(--color-border-soft)`, `var(--color-accent-dim)`, etc.) instead of the sketch's hardcoded `rgba(56,190,201,0.45)`. This fixes gap A12 (inverted colors in dark/light theme) and makes the component theme-aware.

- **laneXOf/rowYOf exported.** The geometry helpers `laneXOf` and `rowYOf` are exported from laneLayout.ts to support plan 06 (VersionHistoryBody alignment) and any test that needs to compute expected positions.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Test assertion `.includes('130')` in laneLayout.test.ts Case 4 caused a false failure**
- **Found during:** Task 1 (implementing laneLayout)
- **Issue:** Case 4's "falseTrunkToV3" check used `.includes('130')` on bezier d strings. The valid v4 bezier `M 22 78 C 56 78 68 130 68 182` has midY=130 (a control point), which caused the check to fire even in the correct implementation. The check was designed to catch beziers that END at v3's row, but `.includes` also matches midY values.
- **Fix:** Changed to `.endsWith(' 130')` which only matches the ENDPOINT y-coordinate (last value in the d string). The valid v4 bezier ends with `68 182`, not `68 130`. A false connector to v3's position would end with ` 130`.
- **Files modified:** `packages/renderer/src/panels/deploy/laneLayout.test.ts`
- **Verification:** All 8 laneLayout tests pass after fix; Case 3's explicit bezier assertion (which still requires midY=130 in d) also passes.
- **Committed in:** `96c3968` (Task 1 commit)
